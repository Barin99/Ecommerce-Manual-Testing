# Ecommerce-Manual-Testing
Manual testing project including Test Plan, Test Cases, Bug Reports, and RTM for a sample e-commerce application
Manual Testing Project - E-commerce Website
📌 Project Overview
This project demonstrates a complete Manual Testing process for an E-commerce web application. Where , this repository contains QA documentation and assets for manual testing of a sample E-commerce web application.

📂 Repository Structure
TestPlan_ECOM-PROJECT.docx → Detailed Test Plan document covering scope, approach, risks, metrics, deliverables, and schedule.
Ecommerce_TestAssets_Consolidate.xlsx → Consolidated Excel file with multiple sheets:
TestCases → 45+ functional test cases across Authentication, Catalog, Cart, Checkout, Payments, and Orders.
BugReport → Sample defect log with severity, priority, repro steps, and environment.
RTM → Requirement Traceability Matrix mapping requirements → test cases → defects.
✅ Contents Overview
1. Test Plan Highlights
Scope: Login/Signup, Catalog Search/Filters, Cart, Checkout, Payments (sandbox), Order history.
Test types: Functional, System, Regression, Smoke, Exploratory, Cross-browser sanity.
Environments: Chrome, Firefox, Edge on Windows/Linux.
Exit Criteria: ≥95% test pass rate, no open P0/P1 defects.
2. Test Cases
45+ structured test cases with IDs, steps, data, expected results, and priorities.
Covers Authentication, Search & Filters, PDP, Cart, Coupons, Checkout, Payments, Orders, and Account.
3. Bug Report
Sample defect log with reproducible issues (e.g., blank password login, duplicate orders, coupon duplication).
4. RTM (Requirement Traceability Matrix)
Maps requirements → test cases → bugs for coverage tracking.
🚀 How to Use
Open TestPlan.docx in MS Word or Google Docs.
Open Ecommerce_TestAssets.xlsx in Excel or Google Sheets.
Use TestCases for execution, BugReport for tracking, RTM for coverage analysis.
Upload updates back to GitHub for version control.
📈 Key Outcomes
Ensured that all major functionalities were covered with proper test cases.
Traced requirements with RTM for 100% coverage.
Reported defects with severity & priority to showcase real testing scenarios.
